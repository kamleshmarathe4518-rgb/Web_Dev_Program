# Web Dev Program 🚀

A collaborative learning project where my friends and I are learning **Web Development** and practicing **Git & GitHub** together.

## 🎯 Goal

* Learn Web Development practically
* Build small projects together
* Learn Git & GitHub workflow
* Practice collaboration and version control
* Improve coding and teamwork skills

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Git
* GitHub

## 🤝 Collaboration

Each member will create branches, work on features, make commits, and create pull requests to practice a real-world development workflow.

## 📚 Learning Approach

**Learn → Practice → Build → Collaborate → Improve**

> Learning together, building together, growing together. 🚀
